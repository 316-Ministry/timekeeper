# How to Use

The workflow is simple:
1. Go to the '**Personnel**' tab and add however many people are on the team (uploading an Excel sheet with **a valid 'Name' column** will allow you to mass upload personnel)
2. Make sure all the names you're adding to the list are unique (**names are case sensitive** as well, so be careful not to add 'jane' and 'Jane')
3. Once you've got names added to the personnel list, you can go to the '**Time Logger**' tab, which allows you to select any given day and log time for each person
4. You can check the total accumulated time for each person on the '**Accumulated Report**' tab (which also allows you to directly export that report to CSV)
5. If you want a **detailed time log** for each person for each day, go to the '**Data Sync & Export**' tab and choose the '**Download Sheet Report**' option
6. If you want to **move from one machine to another**, and want to keep all your data, go to the '**Data Sync & Export**' tab and choose the '**Download Sync File**' option
7. Once you move to the new machine, open the app again, go to the '**Data Sync & Export**' tab and **upload the Sync File (.json) in the 'Import Workspace' section**
